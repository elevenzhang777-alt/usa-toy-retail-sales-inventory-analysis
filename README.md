# USA Toy Retail Sales & Inventory Analysis

## Overview

End-to-end retail data analysis project using SQL, Python, and Power BI to analyse sales performance, profitability, product and category performance, store performance, and inventory risk.

## Dataset

Sales: 245,801 records
Products: 181 products
Stores: 120 stores
Inventory: 14,144 store-product records
Period: January–December 2025

## Tools

MySQL · Python (pandas) · Power BI · PowerPoint

## Key Results

| Metric       |      Result |
| ------------ | ----------: |
| Revenue      |  $9.86M |
| Gross Profit |  $4.31M |
| Gross Margin |  43.66% |
| Units Sold   | 567,270 |

### Key Findings

Store-level Units Sold and Revenue correlation: 0.975
Top 10 products contribute 11.19% of total revenue
Gross margins are relatively stable across stores and throughout the year
Inventory analysis identified 3,469 replenishment-risk and 3,459 potential-overstock SKU combinations

## Business Recommendations

Review pricing and costs in high-revenue, lower-margin categories
Investigate store-SKU inventory risks
Review high-volume, low-margin products
Use sales volume and revenue to investigate store performance
